# Expense Tracker

## Overview

Expense Tracker is a Flutter application to manage daily income and expenses.

## Features

- Add Expense
- Add Income
- Search
- Filter

## Installation

### Clone the repository

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/flutter-expense-tracker.git
```

### Go to project folder

```bash
cd flutter-expense-tracker
```

### Install dependencies

```bash
flutter pub get
```

### Run the application

```bash
flutter run
```
